===========================================================
  FREE GST BILLING SOFTWARE
===========================================================

  Invoices and clients are saved as files under _system/data.
  On this computer they stay in that folder.


-----------------------------------------------------------
  START THE APP
-----------------------------------------------------------

  1. Install Node.js 18 or newer if it is not already installed.
  2. Open a terminal in the _system folder.
  3. The first time only, run:

       npm install

  4. Start the app:

       node server.js

  5. Open this address in your browser:

       http://127.0.0.1:47371/

  Leave that terminal open while you use the app. Closing it
  stops the app.


-----------------------------------------------------------
  YOUR FIRST INVOICE
-----------------------------------------------------------

  1. Settings asks for the business name, address and GSTIN.
     That is what prints on every invoice.

  2. Click "New Invoice".

  3. Type the client's name and GSTIN.

  4. Add what you sold: description, quantity, rate, tax %.

  5. Click "Download PDF".

  For a goods invoice over the e-Way Bill limit, use the
  E-Way Bill button. The same file is saved under
  _system/data/eway/.


-----------------------------------------------------------
  WHERE IS MY DATA?
-----------------------------------------------------------

  In the _system/data folder. Copy that folder to keep a
  backup. A cloud deploy should point DATA_DIR at a
  persistent disk so a restart does not wipe these files.

  See DEPLOY.md for Render and Vercel.
